Tentang Drop

Drop adalah web gratis untuk mengubah sebuah file menjadi alamat web. Tidak perlu akun, tidak ada iklan, dan tidak perlu paham hosting. Pilih file, tunggu sebentar, salin link-nya.

Apa gunanya?

Mengirim file lewat chat sering merepotkan: lampiran terlalu besar, tampilan HTML tidak terbuka, atau orang lain harus mengunduh dulu. Dengan Drop, file kamu langsung bisa dibuka lewat browser hanya dengan satu link.

Manfaat

  • Langsung pakai, tanpa daftar atau login
  • Link pendek yang gampang dibagikan
  • Halaman HTML langsung tampil sebagai web
  • PDF dan gambar terbuka di browser tanpa unduh

Cocok untuk

  • Memamerkan hasil coding atau landing page
  • Undangan dan halaman acara sederhana
  • Membagikan PDF, CV, atau portofolio
  • Mengirim gambar tanpa lampiran
  • Mengetes tampilan file di HP lain
